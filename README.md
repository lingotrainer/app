# Lingotrainer

**→ https://lingotrainer.github.io/app/**

Learn languages in the browser: script, pronunciation, vocabulary – offline, too. No account and no server: your progress stays on your device.

## Install
- **Android (Chrome):** open the page, then menu ⋮ → “Install app” or “Add to Home screen”.
- **iPhone/iPad (Safari):** tap Share, then “Add to Home Screen”.
- **Computer (Chrome/Edge):** click the install icon in the address bar.

## Your progress
It is stored only in this browser on this device. Back it up regularly: ⚙ → “Languages & progress” → Export (a file you can import again later).
